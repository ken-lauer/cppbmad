# pybmad

Python interface to the [Bmad](https://github.com/bmad-sim/bmad-ecosystem) particle accelerator simulation library, built on [cppbmad](https://github.com/ken-lauer/cppbmad).

## API Reference

- [API Index](api/index.md) — searchable listing of all wrapped names
- [Bmad](api/bmad.md) — core Bmad structs and routines
- [Sim Utils](api/sim_utils.md) — simulation utility library
- [Tao](api/tao.md) — Tool for Accelerator Optics
- [Bsim](api/bsim.md) — application-level routines (BBU, etc.)
- [Forest / PTC](api/forest.md) — PTC and Forest library structs
- [Enums & Constants](api/enums.md) — Fortran parameters
